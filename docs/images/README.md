# Wireframe images

Store approved wireframe exports and supporting diagrams in this directory.

## Naming convention

```text
wf-01-room-hub-v01.png
wf-05-buying-negotiation-v02.png
diagram-negotiation-cycle-v01.svg
```

Use lowercase names, two-digit wireframe numbers, and an explicit version suffix.

## Recommended exports

- PNG for screen wireframes and annotated states.
- SVG for system diagrams and flows.
- 2× mobile resolution when text must remain legible on GitHub.
- Dark and light exports only when the difference is relevant to the decision being reviewed.

## Embedding

Place an image directly below the relevant flow or wireframe brief:

```markdown
![Buying negotiation wireframe](images/wf-05-buying-negotiation-v01.png)
```

Do not commit private source art or licensed reference material to this public repository.
